# Docs

`current_ml_pipeline.md` documents the active dataset, training, metrics, and
plotting workflow. It distinguishes grouped out-of-fold validation plots from
final-model diagnostic plots and documents the full-version geometry features,
the generated geometry-template input workflow, and robustness validations.

`repo_cleanup_review.md` records the active full-version source scope, ignored
generated/local folders, retained legacy context, and removed inactive files.

`ml_residual_correction_plan.md` is the original planning document. It is kept
as background context only and may reference older script names, old metrics,
and inactive folder structures. For running the project, use `../README.md` and
`current_ml_pipeline.md`.
